知时课表 iOS 原生 IPA 构建包（无需 Mac，免费云端自动出包）
======================================================

说明：
iOS 原生 .ipa 安装包必须由 macOS 上的 Xcode 编译器生成 ARM64 可执行文件，
本压缩包已内置完整 SwiftUI 原生壳、1024×1024 冰晶图标、完整离线课表核心，
以及 GitHub Actions 免费 macOS 自动编译脚本。

3 步拿到可安装的 ZhishiKebiao-3.1.0-unsigned.ipa：
1. 在 GitHub 新建一个仓库（公开或私有均可），将本压缩包解压后的全部文件上传到仓库根目录。
2. 点击仓库顶部的 Actions 标签页，等待约 2 分钟自动构建完成。
3. 在构建结果底部 Artifacts 下载 ZhishiKebiao-iOS-IPA，即可使用 爱思助手 / AltStore / SideStore / TrollStore 安装到 iPhone。
